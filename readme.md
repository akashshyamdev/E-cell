# Scale '26 — E-Cell BITS Hyderabad Landing Page

I've made a landing page using HTML, CSS and JavaScript for a fictional E-Cell event called Scale.

## Structure

- `index.html` — For the HTML code, and imported the CSS/JS using link
- `style.css` - For all the CSS styles
  `script.js` - Small JS script for toggling the mobile nav
- Google Fonts (Space Grotesk + Inter) are loaded via CDN `<link>` tags — the only
  external dependency.

## Sections

1. **Hero** — Event name, date, venue, registration CTA, with an illustration
2. **About** — Narrative + stat row (mentors, prize pool, past attendance) +
   illustration + highlight list (workshops, mentor hours, pitch finale, community)s
3. **Schedule** — two-day timeline with times and session titles
4. **CTA + footer**

## About the illustrations/Icons

I'm using [Undraw](https://undraw.co/illustrations) for illustractions since I like their clean and elegant style. I've used [Lucide](https://lucide.dev/) for the icons.

## Running locally

No build step needed. Just run index.html.
